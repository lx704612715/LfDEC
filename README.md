# LfDEC project page

Project page for **From a Single Demonstration to a General Policy for Contact-Rich Manipulation** by Xing Li and Oliver Brock, published in *The International Journal of Robotics Research* (2026).

[Website](https://lfdec.github.io/) · [Paper](https://arxiv.org/abs/2605.17601) · [Code](https://github.com/tu-rbo/LfDEC)

The website source is on this repository’s `gh-pages` branch. Edit `index.html` and the assets in `static/`, then push to `gh-pages` to publish the changes automatically.

To preview locally, run:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
